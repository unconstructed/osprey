Overview

Headline state of the lab, read from the files listed in each section below.

Milestones

Milestones and their done-when text come from AGENTS.md; status and notes from dashboard/status.json (edited by hand).

Strategies

The launch strategies from AGENTS.md plus every strategy found in strategies/, reports/ or exports/. Gate values and thresholds are shown exactly as the audit file records them; the overall state is derived from the gates' pass flags, and a missing gate never counts as a pass. Approval for production is the owner's decision.

Search runs
