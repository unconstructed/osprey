## 8. Open items

- **Base cbBTC/USDC vs Coinbase BTC/USD price gap: not measured.** No Base data source (and no 0x quote endpoint) is on the network allow-list, so the gap can't be measured from the allowed sources. It is not estimated here. Measuring it needs the owner to allow a Base data source.
- **DEX cost measurement (0x quotes on Base, Base gas): not done**, for the same reason. `config/costs.yaml` keeps its pessimistic placeholders; no change is proposed.
- **Kraken whole-archive SHA-256: not verified.** The archive is read by HTTP range requests and never held, so the published part SHA-256 sums can't be checked. What is verified: each member's CRC-32 and size, and every range answer carried the part's ETag from the start of the read.
- **Coinbase candles have no published checksum.** The pages are stored as received and hashed. Complete pages are not fetched again, and the newest page is re-fetched on each online build, which changes the snapshot ID.
- **Binance quotes in USDT, not USD.** The Binance/USD differences in the cross-check include the USDT/USD rate. The allowed sources have no USDT/USD series in this build to separate the two.
